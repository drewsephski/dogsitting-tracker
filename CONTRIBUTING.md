# Contributing Guide

Thank you for contributing to **Dog Sit** ([dogsitting-tracker](https://github.com/drewsephski/dogsitting-tracker)). This guide covers the basic workflow from issue to merged PR.

## Getting started

### Fork the repository

Fork the project [on GitHub](https://github.com/drewsephski/dogsitting-tracker).

### Clone the project

Clone your fork locally:

```shell
git clone https://github.com/YOUR_USERNAME/dogsitting-tracker.git
cd dogsitting-tracker
```

### Install dependencies

```shell
pnpm install
```

### Create a branch

```shell
git checkout -b my-new-feature
```

### Make changes locally

See [README.md](./README.md) for environment setup and development scripts.

### Commit and push

```shell
git commit -m 'Describe your change'
git push -u origin my-new-feature
```

### Open a pull request

Open a PR against `main` on [drewsephski/dogsitting-tracker](https://github.com/drewsephski/dogsitting-tracker). Describe what changed and why.

## Issues

- Browse [existing issues](https://github.com/drewsephski/dogsitting-tracker/issues).
- For bugs or features, open a [new issue](https://github.com/drewsephski/dogsitting-tracker/issues/new) with a clear title, steps to reproduce (for bugs), and expected behavior.
